# Unlock PDF

iPhone app for removing the password from a protected PDF — fully offline,
nothing ever leaves the device. Built with Expo (React Native) and TypeScript.

## How it works

1. Pick a password-protected PDF from the Files app — or share one to
   **Unlock PDF** from any app's Share Sheet (Mail, Files, Safari, …) —
   see [docs/share-sheet.md](docs/share-sheet.md)
2. Enter its password
3. Save or share the unlocked copy

The unlocked file is written as a new copy named `<name> (unlocked).pdf`
(never overwriting the original or an existing copy — a counter is appended
if needed).

Decryption is done in pure JavaScript with
[`@cantoo/pdf-lib`](https://github.com/cantoo-scribe/pdf-lib), so it works
offline with no native PDF dependencies.

## Development

```sh
nvm use            # Node 24 (.nvmrc)
npm install
npm run ios        # start Metro and open the iOS simulator
```

Requires Xcode + iOS Simulator for `npm run ios`, or scan the QR code from
`npm start` with a development build on a device.

## Project structure

```
src/
├── app/
│   ├── _layout.tsx       # Root layout (theme + stack)
│   ├── +native-intent.ts # Routes the Share Sheet deep link to the unlock screen
│   └── index.tsx         # The single unlock screen
└── lib/
    └── unlock-pdf.ts     # Core logic: detect encryption, decrypt, save copy
plugins/
└── with-share-extension-name.js  # Shows "Unlock PDF" in the Share Sheet
```

## Notes

- The Share Sheet entry is a share extension generated by `expo-sharing`
  (experimental). It accepts a single PDF, copies it into the
  `group.com.dlhyl.unlockpdf` App Group and opens the app with it selected.
  EAS Build provisions the extension and App Group automatically.
- iPhone-only (`platforms: ["ios"]`, `supportsTablet: false`).
- For unlocking PDFs you are authorized to open and know the password for —
  this is not a password cracker.
- Wrong passwords and already-unprotected PDFs are reported with clear
  error messages in the UI.
